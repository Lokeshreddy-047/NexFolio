# NexFolio

**NexFolio: An Explainable AI Framework for Intelligent Portfolio Risk Profiling and Investment Analytics**

## Features

* Portfolio risk analytics
* XGBoost multiclass risk classification
* SHAP explainable AI engine
* Investor recommendation system
* FastAPI + Spring Boot integration
* React + Tailwind dashboard

## Technology Stack

* **Frontend:** React + Vite + Tailwind CSS
* **Backend:** Spring Boot 3 + FastAPI
* **Database:** MongoDB Atlas
* **ML Frameworks:** XGBoost, SHAP, Scikit-learn, TensorFlow
* **Language:** Java 21, Python 3.11, JavaScript
